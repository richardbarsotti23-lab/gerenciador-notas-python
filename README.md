# Gerenciador de Notas de Alunos

Sistema de gerenciamento de notas de alunos via terminal, desenvolvido em Python.

## 📋 Funcionalidades

- Cadastro de alunos
- Lançamento de notas por disciplina
- Cálculo automático de média geral
- Verificação de situação (Aprovado / Recuperação / Reprovado)
- Boletim individual por aluno
- Remoção de alunos

## 🚀 Como executar

1. Certifique-se de ter o Python instalado (versão 3.6 ou superior)
2. Clone este repositório:
```bash
git clone https://github.com/richardbarsotti23-lab/gerente-notas-python.git
```
3. Execute o programa:
```bash
python gerenciador_notas.py
```

## 🛠️ Tecnologias utilizadas

- Python 3
- Estrutura de dados (dicionários aninhados)
